CLI tool for [iuliia-rust](https://github.com/massita99/iuliia-rust)

Links:  
1. [iuliia](https://github.com/nalgeon/iuliia)

To find out which build you are running, use the `version` command
(`--version` / `-V` print exactly the same line).
The full hash of the commit the binary was built from is reported next to the version:
```
translit version
translit 0.1.0 (abade04e18c423daad72db8f3d1de1233574d736)
```
The hash is `unknown` when the binary was built outside of a git repository.
